## 已确认的问题与修复

`smoke` 原先在标准输出的 JSON 后追加“检查记录”文字，直接用 `JSON.parse` 或 PowerShell `ConvertFrom-Json` 解析整份输出会失败。已把路径提示移到标准错误，终端仍能显示，标准输出保持单个完整 JSON。

原代理集成测试改为直接解析 CLI 标准输出，并核对它与落盘报告一致：修改前测试稳定失败，修改后代理鉴权与 SDK 流式文本、实际只读工具调用两项测试均通过。没有改动候选生成、独立验收或评测规则。

后续用户截图复现了另一个输入缺口：直接发送 `"本地图片路径"描述图片` 时，旧入口仅把路径当作普通文字，图片字节未附加。两个聊天入口现在识别消息开头的本地图片路径：有问题时读取并一起发送，无问题时先排入待发送附件。沿用格式、大小、凭据与本地路径限制，读取失败时清除旧附件，取消加载时不发送迟到图片；普通路径讨论和 URL 不触发自动读取。

新增六项回归先复现失败，修复后定向验证全部通过；完整回归 326 项通过、零失败，类型检查与构建通过。编译版 CLI 经真实 Pi SDK 向本机回环模拟接口提交一张 301429 字节 JPEG，直接提问与先附图两条路径均完整匹配图片字节，模型请求未包含本地文件名或路径。图片未发送给百炼，真实识图回复仍须用户本机验证。证据：`.repopilot/image-inline-red.txt`、`image-inline-green.txt`、`image-inline-sdk-check.json`；完整回归记录为 `image-inline-full-tests.txt`。
