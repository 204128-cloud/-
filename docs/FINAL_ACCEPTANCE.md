## 已知限制

- 修复任务仅覆盖可信本地 JS/TS、SHA-1 Git、package-lock 和 node:test；不保证任意仓库或任意缺陷都可修复。worktree 不提供恶意代码沙箱。
- 模型上下文保留最近八轮及其中最近一张图片，一次附图最大 5 MiB；恢复文字会话后需重新附图。长回复仍受单次输出预算限制，可继续追问。
- 模型不能在会话中动态切换，评测中断后不能从中途恢复；运行产物和工作副本会留存，不会自动清理。
- 当前验证系统是 Windows / Node.js 26.13.0 / npm 11.20.0，没有在所有操作系统或最低版本组合重复运行。
