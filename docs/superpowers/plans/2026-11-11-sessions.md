# Local Conversation Sessions

**Goal:** Explicitly save completed conversations and resume them after restarting, without storing credentials, images or executable tool history.

**Design:** `/save` creates a new UUID snapshot under `.repopilot/sessions`; `/sessions` lists saved metadata, and `/resume <id>` asks before replacing the current conversation. The storage schema contains completed user/assistant text pairs, an image-omitted flag, safe report references and an optional bound-task identity/hash. Model context still uses the most recent eight completed turns; the saved transcript can include more turns within the documented size limit.

## Constraints

- Manual saving only; never automatically persist input, partial replies, images, reasoning, tool arguments, task authorization JSON or credentials.
- Restore data as conversation text, never as instructions to execute tools. Report paths are historical references, not new verification evidence.
- Require the same task identity and byte hash for a bound session. Resume never changes repository permissions or silently binds a task.
- Reject malformed, unsafe or oversized files using fixed safe errors; require UUID IDs, bounded regular-file reads and exclusive snapshot creation.
- Keep drafts, confirmation prompts, Esc cancellation and streaming intact. A failed or declined restore keeps the current conversation.
